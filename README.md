## Data and re-running

Raw Lens exports are not redistributed (see `docs/lens_query.md` for the export description). The scripts expect the raw exports in `lens_export/` and write to the working directories used during the revision (`data_R1/`, `outputs_R1_*`); `outputs/` holds copies of the resulting tables. Run the scripts from the repository root in numeric order.

## Known limitations (manuscript Section 5.1)

- Publication dates are missing for 41% of cited works; fixed windows carry an error of about one year, and priority dates stand in for citing dates.
- The 33 institutions are selected on patent-cited output; institution-level statements apply only to this sample.
- Permutation p-values vary by about +/-.005 (49,999 permutations) and +/-.01 (other tests).
- The transport tag is a keyword screen and was not validated; links were not compared with Reliance on Science.
- Coordinates were carried over from the first-submission scripts and were not independently re-verified.
